🎨 Backup, theme & behavior
Everything here (chat, stats, affection) lives only in this browser. Back it up so switching phones or clearing your cache doesn't lose her.
Overrides the theme above just for these - leave any of them alone to keep the theme's normal color.
Tiny built-in chimes for sending/receiving messages, feeding, gifts, switching companions, and entering Roundgroup - no audio files, generated on the fly.
🔌 Connection
Only needed if your provider blocks direct browser requests (a "Failed to fetch" that isn't your key/network's fault - Cerebras doesn't need this, some others do). Leave blank otherwise.
If the main connection above fails outright (down, overloaded, rate-limited), the app quietly retries through this backup connection instead of showing an error. Needs its own free API key from aistudio.google.com - separate from your main key above, and usable as a standing backup regardless of which main provider you're on.
🧠 Personality & advanced
Separate from the personality prompt above - these always get added on top instead of replacing anything, so you can steer a specific model's quirks ("always end with the STATUS tag", "keep replies short") without touching who Roundbina actually is.
Leave any of these blank to use the provider's own default - only filled-in fields get sent. A weaker/quirkier model (Mistral, etc.) drifting off-instruction or forgetting the STATUS tag is often a temperature-too-high problem, worth trying lower (0.4–0.6) before assuming the model just can't do it.
Note: top_k isn't part of the standard OpenAI schema - most OpenAI-compatible providers (Cerebras included) accept it, but a few silently ignore an unrecognized field rather than erroring, so if it seems to have no effect, that's likely why.
